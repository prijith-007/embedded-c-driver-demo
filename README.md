# Embedded C Driver Development and Testing Demo

## Overview

This repository is a personal learning project demonstrating modular Embedded C development, peripheral-driver architecture, hardware abstraction, and unit testing.

## Objectives

- Demonstrate clean and reusable Embedded C code.
- Separate driver logic from hardware-specific implementation.
- Explore GPIO, ADC, PWM, timer, and watchdog driver interfaces using mock hardware where appropriate.
- Add unit tests for driver logic and error handling.
- Document design decisions, build steps, and testing results.

## Project Status

Initial setup and project structure.

## Planned Structure

- `src/` — Embedded C implementation
- `include/` — Public interfaces and header files
- `tests/` — Unit tests and test doubles
- `docs/` — Design notes and usage documentation
